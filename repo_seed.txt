SECTION 1: WHAT BIOLUMINESCENCE IS AND WHY IT MATTERS FOR ART
=============================================================================

Bioluminescence is light produced by living chemistry — luciferin oxidized by
luciferase, emitting photons in the 440–490nm range (blue-green). But this repo
is not about biology. It's about the mathematical structures that biological
systems discovered first: reaction-diffusion equations, excitable media dynamics,
coupled oscillator synchronization, and advection-diffusion in fluid flows.

These are the same equations that govern:
- how leopard spots and zebra stripes form (Gray-Scott, Turing 1952)
- how cardiac arrhythmias propagate (Fitzhugh-Nagumo)
- how firefly populations synchronize across kilometers (Kuramoto)
- how smoke disperses in wind (advection-diffusion)

The visual language of bioluminescence — glowing lattices in dark water,
traveling pulse rings, synchronized flashes, ink-in-fluid spread — emerges
from these equations without any explicit biological modeling. The organisms
found these solutions. The math was already there.

Art target: dark-field compositions. Near-black backgrounds (#000a14 to
#001a33). Emission only — no ambient light, no surface illumination. Every
photon is generated by the system. The ocean isn't lit. It's generating.

SECTION 2: CORE MATHEMATICS — GRAY-SCOTT REACTION-DIFFUSION
=============================================================================

The fundamental Turing pattern engine. Two chemical species on a 2D grid.

EQUATIONS
---------
  ∂u/∂t = Dᵤ∇²u  −  uv²  +  F(1 − u)
  ∂v/∂t = Dᵥ∇²v  +  uv²  −  (F + k)v

VARIABLES
---------
  u(x,y,t)  activator concentration — "food" / substrate chemical [0, 1]
  v(x,y,t)  inhibitor concentration — bioluminescent pigment / product [0, 1]
  Dᵤ        activator diffusion coefficient
  Dᵥ        inhibitor diffusion coefficient  (always Dᵤ > Dᵥ for Turing instability)
  F         feed rate — rate at which u is replenished from boundary reservoir
  k         kill rate — rate at which v is removed
  uv²       autocatalytic reaction term — v catalyzes its own production by consuming u
  ∇²        discrete Laplacian (5-point stencil):
            ∇²f(x,y) = f(x+1,y) + f(x-1,y) + f(x,y+1) + f(x,y-1) − 4f(x,y)

DISCRETIZATION (Euler explicit, GPU-friendly)
----------------------------------------------
  Δt = 1.0  (per simulation step)
  Δx = 1.0  (unit grid spacing)

  uₙₑₓₜ = u + Δt·[Dᵤ·∇²u  −  uv²  +  F(1−u)]
  vₙₑₓₜ = v + Δt·[Dᵥ·∇²v  +  uv²  −  (F+k)v]

  Clamp both to [0, 1] after each step.
  Run 8–16 simulation steps per render frame for visible evolution speed.

RENDERING
---------
  Luminance = v  (inhibitor field = bioluminescent emission)
  Or: Luminance = smoothstep(0.2, 0.6, v) for sharper emission boundary
  Or: dual-channel — u maps to hue shift, v maps to brightness

PARAMETER SPACE — NAMED REGIMES
---------------------------------
  The (F, k) parameter plane has distinct topology zones. Key ones:

  "coral spawn"       Dᵤ=0.16, Dᵥ=0.08, F=0.037, k=0.060
    → Dense hexagonal spot lattice. Tight glowing circles like coral polyps.
    → Spots are stable, slightly pulsing. Very high v density.

  "deep vein"         Dᵤ=0.16, Dᵥ=0.08, F=0.022, k=0.051
    → Branching labyrinthine stripes. Neuronal networks. Leaf venation.
    → Dark gaps between stripes feel like negative space in deep-sea photography.

  "mitosis"           Dᵤ=0.16, Dᵥ=0.08, F=0.028, k=0.053
    → Self-replicating spots — each elongates and splits. Living cell division.
    → Slowly fills frame from a single seed. Time-lapse biology aesthetic.

  "void dissolution"  Dᵤ=0.19, Dᵥ=0.05, F=0.014, k=0.054
    → Sparse drifting worms / solitons moving through empty dark space.
    → Feels like individual organisms rather than patterns.

  "full spectrum"     Dᵤ=0.16, Dᵥ=0.08, F=0.050, k=0.065
    → Chaotic transition — spots dissolving into mazes dissolving into nothing.
    → The most dynamic, least stable. Use for short renders.

  "kelp forest"       Dᵤ=0.16, Dᵥ=0.08, F=0.029, k=0.057
    → Long vertical stripes with horizontal cross-links. Structural.

  "spawn cloud"       Dᵤ=0.20, Dᵥ=0.05, F=0.055, k=0.062
    → Turbulent spots in constant motion, never settling. Agitated plankton bloom.

INITIALIZATION
--------------
  Default: u=1.0, v=0.0 everywhere except small central seed region (u=0.5, v=0.25)
  Or: random noise — u = 1.0 + noise×0.05, v = 0.0 + noise×0.05
  Interesting: multiple seed patches of different sizes → competing colony growth

SECTION 3: CORE MATHEMATICS — FITZHUGH-NAGUMO EXCITABLE MEDIA
=============================================================================

A spatially-extended excitable medium — every grid point is a simplified neuron
that can fire, propagate activation to neighbors, and enter refractory silence.

EQUATIONS
---------
  ∂v/∂t = D∇²v  +  v(v − α)(1 − v)  −  w  +  I_ext
  ∂w/∂t = ε(βv  −  γw  −  δ)

VARIABLES
---------
  v(x,y,t)  membrane potential / local emission intensity [-0.5, 1.5]
  w(x,y,t)  recovery (refractory) variable — supresses re-firing after pulse
  D         spatial diffusion — how far activation spreads each step (0.1–1.0)
  α         excitation threshold — lower α = easier to trigger [0.10, 0.30]
  ε         timescale ratio — how fast w follows v (0.005–0.05)
             small ε = slow recovery = long dark refractory period
  β         recovery coupling to v (standard: 0.5)
  γ         recovery self-damping (standard: 1.0)
  δ         resting state offset (standard: 0.0)
  I_ext     external stimulus — point sources trigger expanding rings

DISCRETIZATION
--------------
  Δt = 0.01–0.02 (must be small — stiff system)
  Multiple steps per frame (50–100) for visible speed

  v_next = v + Δt·[D·∇²v + v(v−α)(1−v) − w + I_ext]
  w_next = w + Δt·[ε(βv − γw − δ)]

WAVE BEHAVIOR
-------------
  Resting state: v≈0, w≈0 (dark)
  Excitation: v crosses α → rapid jump to v≈1 (bright flash)
  Recovery: w rises → pulls v back down → refractory zone (dark band)
  Propagation: diffusion term D∇²v carries the front to neighbors

  Spiral formation: Break a ring wave (clip half of it).
  The broken end becomes a spiral core. Permanent self-sustaining rotation.
  
  Collision rules: Two wavefronts collide → annihilate (no superposition).
  This is the key visual difference from normal wave interference.

NAMED CONFIGURATIONS
--------------------
  "ring storm"        D=0.30, ε=0.020, α=0.10, β=0.5, γ=1.0
    → Multiple point stimuli → expanding rings → clean annihilation at collision
    → Even, meditative. Like rain drops on a glowing puddle.

  "spiral lock"       D=0.50, ε=0.010, α=0.20, β=0.5, γ=1.0
    → 2–4 permanent counter-rotating spirals. Never decays without perturbation.
    → The dominant visual of dinoflagellate bloom fronts, cardiac tissue.

  "pulse cascade"     D=0.10, ε=0.040, α=0.15, β=0.5, γ=1.0
    → Fast dense wavefronts, overlapping dark zones, high-frequency moiré.
    → Rapid strobing quality — jellyfish bell contraction rhythm.

  "slow bloom"        D=0.80, ε=0.005, α=0.10, β=0.5, γ=1.0
    → Wide slow pulses, very long refractory (dark) zones after each.
    → Feels like a single organism breathing. Big, deliberate.

  "chaos edge"        D=0.20, ε=0.030, α=0.12, β=0.7, γ=1.2
    → Near-chaotic regime — spirals form, break, reform. Never stable.

RENDERING
---------
  Luminance = max(v, 0)  — negative v is dark
  Or: dual-channel — v maps to cyan emission, w maps to violet refractory ghost
  Spiral cores can be highlighted with local phase singularity detection

SECTION 4: CORE MATHEMATICS — FLUID ADVECTION-DIFFUSION
=============================================================================

The bioluminescent emission field treated as a scalar transported by fluid flow.

PRIMARY EQUATION
----------------
  ∂φ/∂t  +  u⃗·∇φ  =  D∇²φ  +  S(x⃗, t)

VARIABLES
---------
  φ(x⃗,t)  emission intensity / light concentration field [0,1]
  u⃗(x⃗,t)  2D velocity field (see construction below)
  D        molecular diffusion coefficient — how much φ smears on its own
           Low D (0.001): sharp filaments, threadlike structures
           High D (0.01): soft volumetric cloud spreading
  S(x⃗,t)  source term — bioluminescent injection rate
           Option A: S = v from Gray-Scott (living reaction-diffusion source)
           Option B: S = mouse position (interactive injection)
           Option C: S = random point bursts (organism disturbance events)
  ∇φ       advection gradient — upwind scheme for stability
  ∇²φ      diffusion Laplacian — standard central difference

VELOCITY FIELD — CURL NOISE (Option A, recommended)
----------------------------------------------------
  Divergence-free by construction (no emission sinks/sources from velocity alone)

  ψ(x,t)  = A₁·fbm(x·f₁ + t·s₁) + A₂·fbm(x·f₂ + t·s₂)
           where fbm = fractional Brownian motion (layered Perlin noise)
           A₁=1.0, f₁=0.003, s₁=0.0005  — large slow eddies
           A₂=0.3, f₂=0.008, s₂=0.0012  — small fast turbulence

  u = ∂ψ/∂y  (finite difference)
  v = −∂ψ/∂x

VELOCITY FIELD — EXPLICIT VORTICES (Option B)
----------------------------------------------
  N discrete vortices, each with position x⃗ᵢ, circulation Γᵢ

  u⃗(x⃗) = Σᵢ  (Γᵢ / 2π) · (x⃗ − x⃗ᵢ)⊥ / (|x⃗ − x⃗ᵢ|² + ε²)
  
  ε = vortex core radius (prevents singularity at center)
  Γᵢ: positive = counterclockwise, negative = clockwise
  Vortices can drift, be mouse-dragged, or appear/disappear over time

NAMED VISUAL CONFIGURATIONS
----------------------------
  "plankton drift"    D=0.002, curl-noise, S=Gray-Scott v field
    → Reaction-diffusion patterns stretched and folded by slow ocean currents
    → The GS spots elongate into comma-shapes, stripe into filaments. Alive.

  "vortex garden"     D=0.001, 5–8 explicit vortices, S=random point bursts
    → Glowing emission spirals into each vortex. Flower-like accumulation.
    → Vortex cores become bright accumulation nodes; edges are dark.

  "turbulent bloom"   D=0.008, high-amplitude curl-noise, S=uniform low level
    → Soft volumetric glow dragged into turbulent filaments and lobes.
    → Resembles deep-sea footage of glowing plankton in wave turbulence.

  "ink in water"      D=0.005, single large vortex + drift, S=central injection
    → Single emission source spirals outward. Bioluminescent dye tracing.
    → Elegant, minimal, high contrast.

SECTION 5: CORE MATHEMATICS — KURAMOTO PHASE SYNCHRONIZATION
=============================================================================

Every spatial grid point is an oscillator with a natural frequency, coupling
to its neighbors through mean-field and spatial diffusion terms.

EQUATION
--------
  ∂θ/∂t = ω(x⃗) + K·r·sin(Ψ − θ) + D∇²θ

VARIABLES
---------
  θ(x⃗,t)   local oscillator phase [0, 2π) — position in its flash cycle
  ω(x⃗)     natural frequency — drawn once from distribution, fixed per point
             Lorentzian: ρ(ω) = (Δ/π) / ((ω−ω₀)² + Δ²)
             ω₀ = mean frequency (2π × flash_rate in rad/s)
             Δ  = frequency spread (wider = harder to synchronize)
  K         global coupling strength — the synchronization force
  r         order parameter magnitude — measures global coherence
             r = (1/N)|Σ exp(iθⱼ)|   range [0,1]
             r ≈ 0: incoherent noise
             r ≈ 1: perfect synchrony
  Ψ         mean phase of the global oscillation
             r·exp(iΨ) = (1/N)Σ exp(iθⱼ)
  D         spatial phase diffusion — smooths phase gradient between neighbors

EMISSION FUNCTION
-----------------
  I(x⃗,t) = cos²(θ/2)       → bright at θ=0, dark at θ=π (smooth pulse shape)
  Or:
  I(x⃗,t) = max(0, cos(θ))  → sharper pulses with hard dark cutoff
  Or:
  I(x⃗,t) = exp(−(θ mod 2π − π)² / σ²)   → Gaussian pulse, width σ

CRITICAL COUPLING THRESHOLD
-----------------------------
  Kc = 2/π · Δ   (onset of synchrony for Lorentzian distribution)

  K < Kc:   r → 0, incoherent — each point twinkles independently
  K = Kc:   r nucleates — sync islands form and grow
  K > Kc:   r → r∞ > 0, partial to full sync depending on K/Kc ratio

  Kc is the single most important parameter. Render near Kc for maximum drama.

NAMED STATES
------------
  "plankton chaos"     K=0.10, Δ=0.80, ω₀=1.0, D=0.05
    → Fully incoherent. Every point twinkles at its own rate.
    → Looks like: starfield, thermal noise, sea spray at night.
    → r < 0.1

  "bloom nucleation"   K=0.80, Δ=0.50, ω₀=1.0, D=0.10
    → Synchronization islands nucleate. Coherent patches drift and merge.
    → The interesting zone — neither random nor locked. Constantly evolving.
    → r ≈ 0.3–0.6

  "shockwave sync"     K=1.50, Δ=0.30, ω₀=1.0, D=0.20
    → System is above Kc. A synchronization front sweeps the field.
    → Most dramatic render: the front is a bright traveling boundary.
    → r goes from 0.2 to 0.85 during the sweep.

  "global pulse"       K=3.00, Δ=0.10, ω₀=1.0, D=0.50
    → Entire field flashes together. Like a heartbeat.
    → Background remains dark; then everything lights up simultaneously.
    → r ≈ 0.95

  "broken symmetry"    K=1.20, Δ=0.40, ω₀=1.0, D=0.02, init=clustered
    → Low spatial diffusion → local sync clusters without global coherence
    → Patchwork of independently-flashing synchronized territories.

SECTION 6: AESTHETIC SPECIFICATION

VISUAL LANGUAGE
---------------
  The aesthetic target: deep-sea darkness, pure emission, mathematical precision.

  Not: fairy lights, nebula stock art, generic glitter, lens flares.
  Yes: bioluminescent wavefronts in dark water, luciferin chemistry made visible,
       the specific cyan of Noctiluca scintillans, the violet of Aequorea victoria.

ORGANISM REFERENCE AESTHETICS (for flavor, not literal rendering)
-----------------------------------------------------------------
  Noctiluca scintillans (sea sparkle): point-like cyan (#00b4d8) flashes,
    distributed randomly, triggered by water turbulence. → Kuramoto "plankton chaos"
    with mouse-disturbance source term in advection layer.

  Dinoflagellate blooms: bright cyan wavefronts sweeping across dark water surface.
    Triggered by wave pressure. → FitzHugh-Nagumo "ring storm" or "spiral lock"
    over advection-diffusion base layer.

  Aequorea victoria (crystal jellyfish): violet-blue (#7b2d8b to #a855f7) emission
    from bell margin, pulsed by spiral waves. → FitzHugh-Nagumo "slow bloom"
    with radial geometry, jellyfish bell shape mask.

  Anglerfish lure: single intense point source, light diffusing into a small sphere.
    → Advection "ink in water" — single injection source, very low D (0.001),
    no velocity field. Pure diffusion. The most minimal possible sketch.

  Ostracod clouds: coordinated blue-green emission in geometric patterns during
    mating displays. → Kuramoto "bloom nucleation" with structured ω frequency map.

  Firefly (Photinus pyralis): bright acid-green (#a8ff78) pulses, 5.5s period,
    specific flash pattern. → Kuramoto with narrow Lorentzian, ω₀=2π/5.5.

RENDERING PHILOSOPHY
--------------------
  Layer order (back to front, additive blend):
    1. Void background (#000a14 or #000000)
    2. Advection-diffusion light field (primary volume)
    3. Gray-Scott emission (structure layer — sharp pattern edges)
    4. FitzHugh-Nagumo pulse fronts (traveling wave overlay)
    5. Kuramoto synchronized bursts (episodic brightening)
    6. Bloom pass (volumetric softening of layers 2–5)
    7. Decay trails (motion history)

  Post-processing stack:
    → HDR: Reinhard tone map (luminance-only, preserves hue)
    → Bloom: dual Kawase, threshold=0.3, 4 levels, intensity=0.8
    → Decay: trail_buffer × 0.95 + new_frame × 0.05
    → Chromatic aberration: RGB ±2px offset at screen edges (water diffraction)
    → Vignette: 1.0 − 0.6 × radial²
    → Film grain: 0.03 amplitude, per-frame noise seed

SECTION 7: GPU IMPLEMENTATION NOTES
=============================================================================

TEXTURE LAYOUT
--------------
  All simulation state stored in 512×512 RGBA32F textures (ping-pong pairs).
  
  Gray-Scott texture:
    .r = u (activator)
    .g = v (inhibitor / emission)
    .b = unused or neighbor sum cache
    .a = emission intensity (post-processed v)

  FitzHugh-Nagumo texture:
    .r = v (membrane potential / emission)
    .g = w (recovery variable)
    .b = age (frames since last excitation — for refractory visualization)
    .a = local emission

  Kuramoto texture:
    .r = θ (phase, packed into [0,1] from [0,2π])
    .g = ω (natural frequency, fixed, packed)
    .b = local order parameter r_local (avg over 5×5 neighborhood)
    .a = emission I(θ)

  Advection-Diffusion texture:
    .r = φ (emission density)
    .g = u_vel (x-component of velocity field — optional, can compute per-frame)
    .b = v_vel (y-component)
    .a = source term S accumulated

SHADER ARCHITECTURE
-------------------
  One fullscreen quad render per simulation pass.
  Uniforms: uTime, uMouse (vec2, [0,1] normalized), uResolution, uDeltaTime
  
  Pass order per frame:
    1. gs_update.frag       — Gray-Scott step (8× per frame)
    2. fn_update.frag       — FitzHugh-Nagumo step (50× per frame)
    3. kuramoto_update.frag — Kuramoto step (1× per frame, recompute r each step)
    4. advection.frag       — Advection-Diffusion step (1× per frame)
    5. composite.frag       — Mix all emission textures with blend weights
    6. bloom_down.frag      — Dual Kawase downsample (4 levels)
    7. bloom_up.frag        — Dual Kawase upsample (4 levels)
    8. decay.frag           — Multiply trail buffer × 0.95, add current emit
    9. output.frag          — Tone map + grain + vignette + chromatic abberation

PERFORMANCE NOTES
-----------------
  GS and FN are the expensive passes (many iterations per frame).
  On low-end hardware, reduce iterations and texture size to 256×256.
  Kuramoto is fast — one pass per frame is sufficient.
  Advection is moderate — upwind scheme requires neighbor reads.
  All passes should target 60fps on mid-range GPU.
